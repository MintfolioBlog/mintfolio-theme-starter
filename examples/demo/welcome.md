## 先看内容，再改样式

这不是空白启动页。示例站点已经准备好不同长度、不同格式的内容，方便你观察主题的表现。

上方封面来自本地 SVG，不依赖外部图片服务。日期、作者、阅读时长与置顶标记来自 Core 的公开元信息。

## 可以从哪里开始

1. 打开文章归档，示例设置为每页三篇，可以直接查看静态分页。
2. 点击分类和标签，观察筛选页与导航地址。
3. 打开系列文章，查看系列目录、上一篇、下一篇和相关文章。
4. 打开密码文章，体验解锁、重新锁定，以及解锁后的正文样式。
5. 查看关于页与阅读清单，对比自动资料页和独立 Markdown 页面。

## 这是一份可以删除的示例

所有人物资料、邮箱、项目介绍与文章都是演示内容。发布自己的博客时请替换它们，不要把虚构资料当成真实个人信息。
